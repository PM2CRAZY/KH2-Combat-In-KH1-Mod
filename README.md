# KH2 Combat for KH1 (install)

The latest build (s339) of [KH2 Combat in KH1](https://github.com/PM2CRAZY/KH2-Combat-in-KH1),
for OpenKH's Mods Manager. Pick Kingdom Hearts Final Mix, then Mods > Install a New Mod and enter
`PM2CRAZY/KH2-Combat-In-KH1-Mod`; tick it and Build. This repository holds only the newest
build (one commit, replaced each release) so it downloads in seconds. The source code is at
[PM2CRAZY/KH2-Combat-in-KH1](https://github.com/PM2CRAZY/KH2-Combat-in-KH1); `README.txt`
has the full guide.
